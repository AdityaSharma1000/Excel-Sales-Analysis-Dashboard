# 📊 Sales Performance Analysis & Interactive Dashboard

## 📌 Overview
A professional-grade analytics solution designed to track business health and sales representative performance. This project, centered around **excel sales anaysis & dashboard project.xlsx**, converts raw transactional data into a visual story for stakeholders.

## 🚀 Key Features
* **🖥️ Interactive UI:** Built a dynamic dashboard featuring Slicers and Timelines for real-time data exploration.
* **📈 Trend Forecasting:** Developed a "Performance Analysis" system to calculate 2025 expected sales growth based on historical averages.
* **⚖️ Comparison Logic:** Implemented Year-over-Year (YoY) and Month-over-Month (MoM) comparison tools.
* **👤 Sales Leaderboard:** Tracks regional manager and sales person performance against set targets.

## 🛠️ Tech Stack
* **Excel Advanced Functions** (Pivot Tables, INDEX/MATCH, VLOOKUP)
* **Data Visualization** (Custom Pivot Charts & Conditional Formatting)
* **Dashboard Design** (Slicers, Timelines, & Layout optimization)

## 📁 Project Structure
* `Raw Data`: Cleaned dataset containing region-wise transactions.
* `Sales DB`: The engine behind the dashboard visualizations.
* `Performance Analysis`: Growth rate calculations and predictive modeling.
